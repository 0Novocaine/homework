
1. Установить зависимости;
2. Загрузить данные авторов в базу данных:
python load_authors.py
3. Загрузить цитаты в базу данных:
python load_quotes.py
4. Запустить скрипт поиска:
python search.py
5. Рабочие команды:
name: Steve Martin - возвращает все цитаты автора
tag:life - возвращает цитаты по одному тегу
tags:life,value - возвращает цитаты, содержащие любой из указанных тегов
exit - выход
